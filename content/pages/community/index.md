## Contributing

Our community builds everything from the Geode code to its documentation, best practices, and
this website. We especially welcome additions and corrections that improve the user experience.

- Report bugs and propose improvements in the [issue tracker](https://issues.apache.org/jira/browse/GEODE).
- Send pull requests to [apache/geode](https://github.com/apache/geode). Start with
  [How to Contribute](https://cwiki.apache.org/confluence/display/GEODE/How+to+Contribute).
- Improve this website in [apache/geode-site](https://github.com/apache/geode-site).
- Help other users on the mailing lists and share best practices.

## Mailing lists

To subscribe, send a blank email to the subscribe address. Discussions are public and archived.

| List | Purpose | Subscribe | Archive |
|------|---------|-----------|---------|
| user@geode.apache.org | Building apps with or deploying Apache Geode. The best place to start with a question. | [user-subscribe@geode.apache.org](mailto:user-subscribe@geode.apache.org) | [Archive](https://lists.apache.org/list.html?user@geode.apache.org) |
| dev@geode.apache.org | Developing contributions and changes to Apache Geode. | [dev-subscribe@geode.apache.org](mailto:dev-subscribe@geode.apache.org) | [Archive](https://lists.apache.org/list.html?dev@geode.apache.org) |
| commits@geode.apache.org | A message for every change committed to Apache Geode. | [commits-subscribe@geode.apache.org](mailto:commits-subscribe@geode.apache.org) | [Archive](https://lists.apache.org/list.html?commits@geode.apache.org) |
| issues@geode.apache.org | A message whenever an Apache Geode issue is created or updated. | [issues-subscribe@geode.apache.org](mailto:issues-subscribe@geode.apache.org) | [Archive](https://lists.apache.org/list.html?issues@geode.apache.org) |

## Getting help

Ask on the [user mailing list](#mailing-lists) or search
[Stack Overflow](https://stackoverflow.com/search?q=Apache%20Geode) for existing answers.

## Events

Want to organize an Apache Geode event? Subscribe to the user list and share your idea there.
For events across the Apache Software Foundation, see
[Apache Events](https://www.apache.org/events/current-event.html).
