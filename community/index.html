Apache Geode Community Resources

The Apache Geode™ community builds and maintains all aspects of the Geode project—from this website to the Geode application code to documentation and best practices information—and we encourage you to get involved.

Getting started​

To get started with Apache Geode, we recommend the following steps:

  1. Follow the tutorial. Begin using Geode in five minutes.
  2. Read the documentation. Learn more about Geode's capabilities.
  3. Consult the wiki. View the community's notes and tips.
  4. Join a mailing list. Meet the Geode community and introduce yourself.
  5. Contribute. Help us improve Apache Geode for everyone.

Mailing Lists​

Join the Geode project's mailing lists.

Users​

If you're getting started with Geode, building apps against Geode, or deploying Geode, then this is the place to start. To subscribe, send a blank email to:

user-subscribe@geode.apache.org

You can also read the archives.

Developers​

If you are planning to contribute modifications to Apache Geode, then this is the list for you. To subscribe, send a blank email to:

dev-subscribe@geode.apache.org

You can also read the archives.

Commits​

This list receives an email whenever someone contributes new code to Apache Geode. To subscribe, send a blank email to:

commits-subscribe@geode.apache.org

You can also read the archives.

Issues​

This list receives an email whenever someone creates or updates an Apache Geode issue. To subscribe, send a blank email to:

issues-subscribe@geode.apache.org

You can also read the archives.

Contribute to Geode​

We welcome all forms of contribution. We especially welcome additions and corrections to the documentation, wiki, and website that improve the overall experience of using Geode. Filing bug reports and offering fixes to the Apache Geode code are also excellent ways to contribute to the project.

How to contribute​

  • Find a big to fix by reviewing open issues in the issue tracker
  • Check current pull requests and help review them
  • Review documentation on the Geode wiki and update it
  • Propose changes to the Geode project website

For complete contribution instructions, see How to Contribute in the Geode wiki.

Project Governance​

Geode is an Apache Software Foundation (ASF) project. As such, the Geode community strives to work according to the Apache Way, and we adhere to the ASF's code of conduct.

Committee​

Governing every ASF project is a Project Management Committee (PMC). Members of Geode's PMC oversee project development and releases. Additionally, Geode committers help maintain the codebase. See Geode's committee roster for a complete list of participants.

Board minutes​

The ASF board regularly reports on Geode project status at board meetings. Review these reports in the meeting notes.
