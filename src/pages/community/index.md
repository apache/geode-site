# Apache Geode Community Resources

The Apache Geode™ community builds and maintains all aspects of the Geode project—from this website to the Geode application code to documentation and best practices information—and we encourage you to get involved.

## Getting started {#getting-started}
To get started with Apache Geode, we recommend the following steps:

1. [Follow the tutorial](https://cwiki.apache.org/confluence/display/GEODE/Index#Index-Geodein5minutesGeodein5minutes). Begin using Geode in five minutes.
1. [Read the documentation](https://geode.apache.org/docs/). Learn more about Geode's capabilities.
1. [Consult the wiki](https://cwiki.apache.org/confluence/display/geode/). View the community's notes and tips.
1. [Join a mailing list](/community#mailing-lists). Meet the Geode community and introduce yourself.
1. [Contribute](/community#contributing). Help us improve Apache Geode for everyone.

## Mailing Lists {#mailing-lists}

Join the Geode project's mailing lists.

### Users
If you're getting started with Geode, building apps against Geode, or deploying Geode, then this is the place to start.
To subscribe, send a blank email to:

`user-subscribe@geode.apache.org`

You can also [read the archives](https://lists.apache.org/list.html?user@geode.apache.org).

### Developers
If you are planning to contribute modifications to Apache Geode, then this is the list for you.
To subscribe, send a blank email to:

`dev-subscribe@geode.apache.org`

You can also [read the archives](https://lists.apache.org/list.html?dev@geode.apache.org).

### Commits
This list receives an email whenever someone contributes new code to Apache Geode.
To subscribe, send a blank email to:

`commits-subscribe@geode.apache.org`

You can also [read the archives](https://lists.apache.org/list.html?commits@geode.apache.org).

### Issues
This list receives an email whenever someone creates or updates an Apache Geode issue.
To subscribe, send a blank email to:

`issues-subscribe@geode.apache.org`

You can also [read the archives](https://lists.apache.org/list.html?issues@geode.apache.org).

## Contribute to Geode {#contributing}
We welcome all forms of contribution.
We *especially* welcome additions and corrections to the documentation, wiki, and website that improve the overall experience of using Geode.
Filing bug reports and offering fixes to the Apache Geode code are also excellent ways to contribute to the project.

### How to contribute

- Find a big to fix by reviewing open issues in the [issue tracker](https://issues.apache.org/jira/projects/GEODE/issues)
- Check [current pull requests](https://github.com/apache/geode/pulls) and help review them
- Review documentation on [the Geode wiki](https://cwiki.apache.org/confluence/display/GEODE/) and update it
- Propose changes to the [Geode project website](https://github.com/apache/geode-site)

For complete contribution instructions, see [How to Contribute](https://cwiki.apache.org/confluence/display/GEODE/How+to+Contribute) in the Geode wiki.

## Project Governance {#project-governance}
Geode is an Apache Software Foundation (ASF) [project](https://projects.apache.org/).
As such, the Geode community strives to work according to the [Apache Way](https://www.apache.org/theapacheway/), and we adhere to the ASF's [code of conduct](https://www.apache.org/foundation/policies/conduct).

### Committee
Governing every ASF project is a [Project Management Committee](https://www.apache.org/dev/pmc.html) (PMC).
Members of Geode's PMC oversee project development and releases.
Additionally, Geode committers help maintain the codebase.
See [Geode's committee roster](https://projects.apache.org/committee.html?geode) for a complete list of participants.

### Board minutes
The ASF board regularly reports on Geode project status at board meetings.
Review these reports in [the meeting notes](https://whimsy.apache.org/board/minutes/Geode.html).
